# 프로젝트 성능 리포트

상세 아키텍처·개선 포인트는 PROJECT_ANALYSIS.md(작성 시) 참조. 본 문서는 **성능 수치·목표·이슈**에 초점을 둡니다.

## 1. API·처리 성능

| 항목 | 현재(참고) | 비고 |
|------|------------|------|
| **데이터셋 생성** | 수집·전처리·포맷 변환 시간 | 목표치 설정 권장 |
| **전처리** | 이미지 리사이즈·letterbox 등 | 환경에 따라 변동 |

- **측정**: 구간별 로그·타이밍 추가 후 목표 구간 설정 권장.
- **병목**: 대량 이미지 처리 시 I/O·메모리 고려.

## 2. 리소스

| 항목 | 내용 |
|------|------|
| **메모리** | 대량 이미지 로드 시 피크 고려. 배치 처리 권장. |
| **디스크** | 데이터셋 용량·경로 정책 정의 권장. |

## 3. 개선 권장

| 우선순위 | 항목 | 기대 효과 |
|----------|------|-----------|
| 1 | 입력 검증(파일 타입·최대 크기) | 오용 방지, 리소스 보호 |
| 2 | 헬스체크 엔드포인트(`/health`) | 운영·모니터링 용이 |

성능 목표는 운영 요구에 따라 수치를 정한 뒤 본 문서에 반영하는 것을 권장합니다.
